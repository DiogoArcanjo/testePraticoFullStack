# Plano

## Ordem
1. Criar projeto React + TypeScript com Vite
2. Configurar rotas
3. Tela de lista com dados mock
4. Busca, ordenação e paginação com filtros na URL
5. Formulário de cadastro/edição
6. Tela de detalhes
7. Tela de clima com dados mock

## Riscos
- Pouca experiência com React/TS: começar simples e validar cada tela antes de seguir.
- Sem backend: usar mock e deixar fácil trocar pela API depois.

## Checkpoints
- Após cada tarefa: rodar `npm run dev` e testar no navegador.
